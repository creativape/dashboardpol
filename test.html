📋 Instrucciones: qué archivos subir a Vercel
Para que este diagnóstico funcione necesitas 4 archivos en esta estructura:
tu-proyecto/
├── index.html ← el dashboard principal
├── test.html ← esta página de diagnóstico
└── api/
    ├── dashboard.js ← la API principal
    └── dashboard-test.js ← endpoint de diagnóstico
Variables de entorno en Vercel → Settings → Environment Variables:
ANTHROPIC_API_KEY = sk-ant-api03-...
NEWSDATA_KEY = pub_...
Importante: Después de agregar variables de entorno, siempre haz un nuevo deploy desde el panel de Vercel para que los cambios tomen efecto.
